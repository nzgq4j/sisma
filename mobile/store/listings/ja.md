# Google Play store listing (ja-JP)

## Short description

世界の地震をリアルタイムで。地図、3D地球儀、近くの地震のアラート

## Full description

揺れを感じたら、sismaを開いてください。何が起きたのか、どこで、どれくらいの強さだったのかがわかります。

sismaは、世界中の地震をリアルタイムで追える地震情報アプリです。USGS、EMSC、GeoNet、JMA(気象庁)の4つの機関の情報をまとめ、同じ地震は1件として表示。マグニチュード、震源の深さ、発生時刻、あなたからの距離がひと目でわかります。日本、インドネシア、フィリピンから、トルコ、イタリア、ギリシャ、カリフォルニア、メキシコ、チリ、ニュージーランドまで、世界の地震活動をチェックできます。

いま、どこで揺れた?
• 新しい順・近い順・強い順に並べ替えられる地震リスト
• すべての地震のマグニチュード、深さ、時刻、距離に加え、国と精査済みかどうかも表示
• 周辺表示で地震の周りを拡大し、近くで起きた地震も表示。余震の様子を追えます
• タブレットでは、1日ごとの発生数、マグニチュード別の件数、活動の多い地域をまとめた概要画面

リアルタイム地震マップと3D地球儀
• 現在地を中心にした世界地図に、プレート境界を表示
• 地球全体から街のレベルまでズーム
• 3D地球儀を回し、深さ表示に切り替えると、それぞれの地震の震源の深さがわかります
• 期間と場所で絞り込み

揺れを感じましたか?
• 地震発生から数時間以内に、感じた揺れを報告
• ほかの人が揺れを感じた場所を揺れマップで確認(地域ごとの匿名の件数のみ表示)

地震をシェア
• 周辺の地図入りの画像で地震をシェア。投稿文と画像の説明文はあらかじめ用意され、編集もできます

地震のしくみを知る
• 7つのイラスト付きガイド:プレートテクトニクス、断層の種類、地震波、マグニチュードと震度(リヒタースケールとの関係も)、震源の深さ、津波、そして地震への備え

sisma+(任意のサブスクリプション)
• スマートフォンに地震アラート:条件に合う地震が起きるとプッシュ通知でお知らせ
• 最小マグニチュード、保存した場所からの距離、国や世界の地域を設定。アラートルールは最大5件
• おやすみ時間を設定でき、大きな地震だけは通知を受け取ることも可能
• 保存できる場所は最大10か所(無料プランは1か所)
• 最大1年分の地震の履歴(無料プランは直近30日間)
• マグニチュードと世界の地域による絞り込み
• 新規登録の方は7日間無料でお試しいただけます。その後は月額または年額。Google Playでいつでも解約できます。

そのほかの機能はすべて無料で、広告もありません。

英語、スペイン語、日本語、インドネシア語、トルコ語、イタリア語、ポルトガル語、中国語、フランス語、ドイツ語に対応。ライトテーマとダークテーマを選べます。

データ:USGS(アメリカ地質調査所)、EMSC(欧州地中海地震学センター)、GeoNet(ニュージーランド)、JMA(気象庁)

ご注意
sismaは公式の警報サービスではなく、緊急地震速報は提供していません。必ずお住まいの地域の自治体や公的機関の指示に従ってください。
